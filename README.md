# poetry_land — 诗词交互探索平台

一个基于 Streamlit 构建的交互式中文诗词探索 Web 应用。内置 222 首经典诗词，支持飞花令搜索、AI 诗词生成、诗人风格对比、情感分析等六大功能模块。

---

## 功能特性

### 🌸 飞花令搜索
侧边栏输入单个汉字，一键搜索所有包含该字的诗句，以表格形式展示诗句、诗名、作者和朝代。  
搜索结果中随机选取一句作为 **AI 对曰** 回复，增加互动趣味。  
基于 scikit-learn TfidfVectorizer 的文本向量化检索，推荐语义相似的诗作。

### ✍️ 诗词生成器（马尔可夫链）
基于内置诗词，分别训练**豪放、婉约、田园**三种风格的二阶马尔可夫链。  
用户选择风格后，AI 基于训练数据即兴生成一首五言或七言绝句（4 句），并展示生成所参考的原始诗句片段。

### 👥 诗人风格对比
从数据中自动提取所有诗人，选择任意两位进行对比：  
- **高频词对比** — Plotly 柱状图展示各自 Top 10 高频词  
- **情感极性分布** — 直方图对比两位诗人的情感得分分布  
- **统计指标** — 诗作数量、平均句长、总用字数、独特词汇数  

### 💭 情感分析
内置 200+ 正面/负面情感词典（基于古诗词常见意象字）。  
支持从列表选择诗作或手动输入诗句，计算**情感指数**并以进度条可视化，同时展示正面/负面词统计。

### 📊 数据看板
主页底部自动展示：总诗数、作者数、朝代分布饼图（Plotly）、最常用字词 TOP10 表格。

### 📥 全量数据加载
可选功能：点击按钮从 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) GitHub 仓库下载唐诗宋词 JSON 数据，合并入当前数据集。

## 快速开始

### 环境要求

- Python 3.9+
- pip

### 安装与运行

```bash
# 1. 克隆仓库
git clone https://github.com/h314159-ar/-Streamlit-.git
cd -Streamlit-

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动应用
streamlit run app.py
```

或使用 Python 模块方式启动：

```bash
python -m streamlit run app.py
```

启动后终端会显示本地 URL，默认 `http://localhost:8501`，浏览器打开即可使用。

### 依赖清单

```
streamlit
plotly
scikit-learn
pandas
jieba
requests
```

## 数据说明

- **内置数据**：222 首诗词硬编码在 `app.py` 顶部，涵盖唐、宋、五代、元、明、清等朝代，分为豪放（68 首）、婉约（75 首）、田园（79 首）三种风格。
- **外部数据**（可选）：点击"加载全量数据"从 chinese-poetry 开源仓库下载唐诗宋词 JSON（每文件约 1000 首），合并入当前会话。
- 程序**不依赖外部文件**即可独立运行。

## 设计思路

### 技术选型

| 需求 | 选型 | 理由 |
|------|------|------|
| Web 框架 | Streamlit | 纯 Python，快速原型，无需前端经验 |
| 可视化 | Plotly | 交互式图表，与 Streamlit 无缝集成 |
| 文本向量化 | scikit-learn TfidfVectorizer | 轻量级，仅用于相似诗作检索 |
| 中文分词 | jieba | 中文 NLP 标准工具，诗词分词效果好 |
| 情感分析 | 自定义词典 | 基于古诗词意象的正面/负面字词库，无需训练 |

### 情感词典构建
- **正面词**：春、花、月、明、清、笑、歌、乐、碧、翠、悠、畅等 200+ 字
- **负面词**：愁、恨、悲、泪、寒、孤、独、凄、残、萧、瑟等 200+ 字
- 评分公式：(正面词数 − 负面词数) / (正面词数 + 负面词数)，范围 [−1, 1]

### 马尔可夫链
- **阶数**：二阶（根据前两个词预测下一个）
- **分词**：jieba 精确模式
- **生成格式**：五言或七言绝句（4 句），通过格式约束确保可读性

### UI 设计
参考了 "Premium Utilitarian Minimalism" 设计理念，采用：
- 宣纸底色 #F5F0E8 + 墨色文字 #3A2A1A
- 朱砂红 #C04040 作为强调色（仿中式印章）
- Noto Serif SC 字体用于诗词展示
- 扁平卡片 + 细微阴影，克制使用渐变

## 实验结果说明

- **飞花令搜索**：搜索"月"可返回 40+ 相关诗句，响应时间 < 0.5s
- **诗词生成**：三种风格各训练约 2000 个转移对，生成文本在词汇层面有原文影子，但组合方式不重复
- **情感分析**：对"问君能有几多愁恰似一江春水向东流"分析得分为 −0.33（倾向低沉），与人工判断一致
- **朝代分布**：数据涵盖唐、宋、五代、晋、汉、元、明、清等朝代
